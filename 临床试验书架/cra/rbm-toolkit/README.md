# RBM 监查工作台 · 使用说明

> CRA 基于风险的监查（Risk-Based Monitoring）在线工具包
> 核心模块：RACT 数字化评分系统 · 动态风险台账 · 本次监察详情 → 监察清单 → 监察记录

---

## 一、这是什么

把 RBM 体系的三套方法论文具，做成了**零安装、零后端、可离线**的在线工具：

| 模块 | 解决的问题 | 核心能力 |
|---|---|---|
| **RACT Builder** | 风险识别停留在口头、无法量化排序 | 9 大类别 58 个条目，填空即打分 → 自动算 RPN → 自动归类 → 自动输出监查策略 |
| **Risk Ledger** | 风险事件散落在邮件和 Excel，无法闭环 | 全生命周期账本：事件 → 整改 → 升级 → 闭环 → 复盘，带看板与趋势 |
| **Visit Checklist** | 每次访视都用同一张通用清单，漏检率高 | 「本次监察详情」按「中心 RPN + CtQ + 历史高频问题 + 残留问题 + KRI 异常」自动生成监察清单，确认后归档到「监察记录」 |

所有数据保存在**浏览器本地（localStorage）**，不上传任何服务器 —— 天然满足临床数据不出域的合规要求。

---

## 二、三种使用方式

### 方式 1：直接双击打开（离线，最简单）
解压后**双击 `index.html`**，在浏览器（推荐 Chrome / Edge）中即可使用。首次打开自带一套示范项目（XYZ-301，6 家中心），可直接体验全部功能。

> 无需联网、无需安装、无需注册。适合 CRA 个人在中心现场使用。

### 方式 2：在线访问（已部署）
工具已部署到 EdgeOne Makers，扫码或点链接即可打开：

- **在线地址**：见随包的 `qrcode-在线访问.png`（二维码内含完整访问链接）
- 页面右上角「分享 / 二维码」中会**自动生成当前地址的工具访问二维码**

> ⚠️ EdgeOne 预览域名链接带访问令牌，会随时间对**新访客**失效。
> 若链接打不开，请用方式 3 重新部署，或直接离线使用（方式 1）。
> `qr-generator.html` 是随包附带的离线二维码生成器，可随时为任意地址重出二维码。

### 方式 3：部署到自己的服务器（团队长期使用）
整个工具包是**纯静态文件**，任意静态服务器都能跑：

```bash
# Nginx：把目录扔到站点根目录即可
server { listen 80; server_name your.domain; root /var/www/rbm-toolkit; index index.html; }

# 或 Python 一行起服务
python -m http.server 8080
```

团队共用时建议部署到内网，或为 EdgeOne 项目绑定**已备案的自定义域名**以获得长期稳定访问。

## 三、五分钟上手（标准工作流）

```
① RACT 评分 → ② 生成监查策略 → ③ 风险台账闭环 → ④ 生成访视清单 → ⑤ 访视报告
```

**① RACT 风险评估**
进入「RACT 风险评估」→ 用「评分向导」按类别逐类打分（上一类 / 下一类翻页）。
每个条目打三个分：**概率 P**（会不会发生）、**影响 I**（后果多严重）、**可检测度 D**（越难发现分越高）。
系统自动算 RPN = P × I × D，按级别着色，并加权汇总为 **0–100 综合风险指数**。
点「保存评估」可存档到评估库；「导出 PDF」可输出评估报告。

**② 生成监查策略**
切到「监查策略建议」标签 → 系统按类别风险占比输出：现场监查频率、SDV 比例、升级路径、各类别针对性动作。

**③ 动态风险台账**
进入「动态风险台账」→ 新建条目，或点「⟳ 从中央监查 / KRI 抽取」让系统自动扫描候选风险。
记录整改动作、责任人、Due Date；需要上级介入时勾选「升级至 PM/QA」；闭环时填写复盘结论。
看板视图可按**中心 / 风险等级 / SOP 类型**自由切换；「趋势」标签可看 6 个月风险走势。

**④ 本次监察详情 → 监察清单**
进入「本次监察详情」→ 选**中心 / 访视类型 / 访视日期**（紧凑排列）→ 点「确认」进入执行页。
监察清单按中心风险画像自动生成，每一项都标注了**纳入依据**和**优先级**（强制 / 重点 / 常规）。
清单条目默认收起，点击展开逐项核查，可标记「符合 / 一般问题 / 重大问题 / 不适用」并写备注；支持**扫码签到（含 GPS）**与**拍照取证**。

**⑤ 归档与报告**
全部核查完成后点条目区右下角的绿色「确认」按钮 → 本次监察自动归档到工作区的**「监察记录」**。
在「监察记录」中可查看详情、**导出 Word 报告**（可直接用 WPS / Word 打开编辑、保存、打印），并可离线同步数据。

## 四、个人中心与操作轨迹

- **角色**：本工具为 CRA 单角色设计，无需切换角色。
- **头像**：点击左下角头像 → 弹出个人面板，可**上传头像**、修改姓名。
- **最近操作轨迹**：在头像面板中点「最近操作轨迹」进入只读子页面，支持**按日期范围筛选**、搜索与导出 CSV，全程留痕不可编辑。

---

## 五、数据管理与合规

- **存储位置**：全部数据在本机浏览器 localStorage，不经过任何第三方服务器。
- **离线同步**：「监察记录 → 离线数据同步」可导出/导入 JSON 数据包，现场离线填完，回办公室并入主库。
- **数据迁移**：换电脑时导出数据包在新设备导入即可。
- **操作轨迹**：点头像 → 「最近操作轨迹」记录全部操作（时间 / 用户 / 操作 / 对象 / 详情），只读、可按日期筛选，可导出 CSV 供稽查。
- **重置**：「分享 / 二维码」页底部可一键重置回示范数据。

## 六、方法论依据

- **ICH E6(R2/R3) GCP** — 申办者应建立基于风险的质量管理体系，采用风险比例化的监查策略
- **TransCelerate RACT** — 风险评估分类工具的类别与子项框架
- **FMEA 风险优先数（RPN）** — 概率 × 影响 × 可检测难度；本工具中 D 定义为「越难发现分越高」
- **CtQ（Critical to Quality）** — 识别对数据可靠性与受试者安全至关重要的环节
- **KRI 关键风险指标** — 量化监测 + 警戒阈值，触发式监查的决策依据

> 本工具是方法论落地载体。评分锚点、阈值与监查策略需结合具体方案、SOP 与法规要求，由质量团队审定后使用。

## 八、自检

在地址后加 `?diag=1` 可运行内置自检（覆盖全部视图渲染、评分计算、清单生成、二维码生成），结果写入页面 `#diag-result` 节点。正常情况所有视图均显示 `OK` 且 `errs=none`。
