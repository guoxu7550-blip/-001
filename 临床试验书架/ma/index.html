肿瘤 实体瘤 + 血液肿瘤

OS（Overall Survival）：总生存期，从随机至全因死亡。金标准终点，所需样本大、随访长，但最客观。

PFS（Progression-Free Survival）：无进展生存期，从随机至首次疾病进展或全因死亡（取先发生者）。加速审批常用替代终点。

DFS（Disease-Free Survival）：根治术后辅助治疗场景下，从随机至复发或死亡。

ORR（Objective Response Rate）：客观缓解率，CR + PR 比例，RECIST 1.1 标准评估。

DCR（Disease Control Rate）：疾病控制率 = CR + PR + SD。

pCR（pathologic Complete Response）：病理完全缓解，乳腺癌新辅助试验常用。

评估标准：RECIST 1.1（实体瘤）；iRECIST（免疫治疗）；Lugano 2014（淋巴瘤）；IWG 2003（血液肿瘤）。

常见驱动基因及对应靶向药：

· EGFR（19del / L858R / T790M / C797S）：非小细胞肺癌（NSCLC）
· ALK / ROS1 融合：NSCLC
· BRAF V600E：黑色素瘤、甲状腺癌、结直肠癌
· HER2（过表达/扩增）：乳腺癌、胃癌、子宫内膜癌
· KRAS G12C：NSCLC、结直肠癌
· BRCA1/2 突变：卵巢癌、乳腺癌、前列腺癌（PARP 抑制剂）
· NTRK / RET / MET 融合：泛瘤种
· PD-L1 表达（TPS/CPS）：免疫检查点抑制剂富集/分层

FDA 要求伴随诊断（CDx）与靶向药同步获批；试验中通常要求中心或中心化实验室做 NGS / IHC / FISH / PCR 检测。

参考：NCCN / ESMO 临床实践指南；FDA CDx 数据库。

① 大多数注册研究采用1:1 随机 + 开放标签（开放更常见）+ 独立中心评审（IRC）评估影像，避免评估者偏倚。

② 加速审批常以 PFS / ORR 替代终点 + 确证性 OS 研究。

③ 富集设计（仅入组生物标志物阳性）可减少样本量，但限制可推广性。

④ 免疫治疗常用亚组分析探索 PD-L1 / TMB / MSI-H / dMMR / 基因表达谱。

⑤ 联合治疗：研究多个剂量组合，需考虑叠加毒性、PK 相互作用、序贯 vs 同时。

⑥ IRB / EC 对高风险方案（如 CAR-T、双特异性抗体）须更严格审查。

设计原则：ICH E9、E10、E17（多区域试验）；FDA/EMA 抗肿瘤药物指南。

常见免疫相关 AE（irAE）：皮肤（皮疹、白癜风、瘙痒）、内分泌（甲减/甲亢、垂体炎、1 型糖尿病、肾上腺功能不全）、消化（结肠炎、肝炎）、肺（免疫性肺炎）、神经（脑炎、重症肌无力、格林-巴利）、眼（葡萄膜炎）、心（心肌炎——少见但凶险）、肾（间质性肾炎）、关节（关节炎）。

关键概念：假性进展（先增大后缩小，6–8 周复评，必要时 iRECIST）；超进展（HPD，疾病反加速，需早期识别）；耐药机制（原发 vs 获得性）。

管理：ASCO/SITC/NCCN irAE 指南（按 CTCAE 分级处理）。

心血管 CVD

· MACE（Major Adverse Cardiovascular Events）：常为 3P-MACE（CV 死亡 + 非致命 MI + 非致命卒中）或 4P-MACE（+ 因不稳定心绞痛血运重建）；
· 全因死亡 / CV 死亡：长期预后金标准；
· 心衰住院：HFpEF/HFrEF 治疗试验主要终点；
· NT-proBNP / BNP 变化：心衰生物标志物替代终点；
· LDL-C / Lp(a) / HDL-C：调脂药生物标志物终点；
· 冠脉/血管影像学（PAV、TAV、FFR、IMR）；
· 6 分钟步行试验 / NYHA 分级 / KCCQ：心衰功能终点。

指南参考：ACC/AHA、ESC、CCS 各类适应症指南。

· hs-cTnI/T：心肌损伤标志物，ACS 诊断、风险分层；
· NT-proBNP / BNP：心衰诊断与预后；
· Lp(a)：独立动脉粥样硬化风险因子，新药靶点（pelacarsen、olpasiran）；
· LDL-C / ApoB：调脂治疗核心；
· hs-CRP / IL-6：残余炎症风险（LoDoCo2、ZEUS）；
· Galectin-3 / sST2：心衰纤维化指标；
· NT-proBNP-guided therapy：指导心衰治疗（GUIDE-IT 等研究）。

建议：心衰新药试验常以「CV 死亡 + 心衰住院」复合终点；样本量计算需考虑事件驱动设计与随访时间。

① 多数心血管结局研究为事件驱动设计，大型、长期（5 年+）、大样本（数千至上万）。

② 须独立临床事件委员会（CEC）裁定 MACE；3 期常设 DSMB。

③ 背景治疗标准化：高强度他汀、抗血小板、降压、GLP-1RA / SGLT2i 等应纳入标准化背景，否则影响效应量。

④ 高风险人群（糖尿病、CKD、外周动脉疾病）常被富集。

⑤ 依从性是关键挑战——长期开放标签下，crossovers、停药率、知情同意后失访是常见问题。

关键：与常规治疗组（standard of care arm）的真实世界依从性、地区性诊疗差异、终点获取（电子病历/保险数据库）需提前规划。

自身免疫 RA / SLE / IBD / PSO

· 类风湿关节炎（RA）：DAS28-CRP/ESR、SDAI、CDAI；ACR20/50/70 应答率；HAQ-DI（功能）；影像学 Sharp/van der Heijde 评分。
· 系统性红斑狼疮（SLE）：SLEDAI-2K、BILAG 2004、PGA；SRI-4、CLASI（皮肤）。
· 银屑病（PSO）：PASI 75/90/100、sPGA、DLQI。
· 克罗恩病 / 溃疡性结肠炎（CD/UC）：CDAI、Mayo Score、内镜 Mayo SES-CD；histologic remission。
· 强直性脊柱炎（AS）：ASAS20/40、ASDAS、BASDAI、BASMI。

指南：EULAR、ACR、GRAPPA、IOIBD、ASAS。

· TNF-α 抑制剂：英夫利昔、阿达木、依那西普、戈利木、培塞利珠。
· IL-6R 抑制剂：托珠、萨瑞鲁、沙利鲁。
· IL-17A 抑制剂：苏金、依奇珠、柏地珠。
· IL-23 / IL-12 抑制剂：乌司奴、古塞奇珠、瑞莎珠。
· IL-4Rα 抑制剂：度匹鲁（AD）。
· B 细胞靶向：利妥昔（CD20）、贝利尤（BAFF）。
· JAK 抑制剂：托法替布、巴瑞替尼、乌帕替尼（非选择性 JAK，注意 FDA 黑框）。
· 细胞治疗：CAR-T（自身免疫适应症探索中）。

安全性：感染（结核、HBV 复燃、PJP）、机会性感染、肿瘤、心血管事件、肠穿孔。

处方前应筛查结核、HBV、HIV；定期监测血常规、肝功。

① 多数为 12–24 周双盲安慰剂对照，伴随长期延伸（LTE）评估持续获益/安全；② 难治性/失败史定义需在方案明确；③ 合并 csDMARD（甲氨蝶呤等）背景标准化；④ 一线失败后换药研究需设背景人群清晰；⑤ 终点的最小临床重要差异（MCID）提前定义；⑥ 影像学/内镜中心化阅片是质量控制关键。

感染 抗病毒 / 抗菌 / 疫苗

· 微生物终点：病原清除率、抗菌耐药（MIC、MPC、突变选择窗）；
· 临床终点：临床治愈率、30 天全因死亡（重症感染）、症状缓解时间；
· PK/PD 目标：fAUC/MIC、Cmax/MIC、%T > MIC；
· 非劣效界值：常 10–15%（NI margin），需预先 SAP 论证；
· 新生儿 / 儿童：剂量探索需 PK 桥接 + 安全性队列。

指南：FDA/EMA 抗菌药开发指南；CLSI/EUCAST 折点。

· HIV：HIV-RNA 病毒载量（< 50 copies/mL）、CD4、长期安全性、停药风险；功能性治愈研究用 ART 干预+免疫调节。
· HCV：SVR12 / SVR24（持续病毒学应答），直接抗病毒药物（DAA）已使 HCV 大部分治愈。
· HBV：HBsAg 消失或血清转换、HBV-DNA 抑制、HBeAg 转换。
· SARS-CoV-2：轻中度（症状缓解、住院或死亡）、重度（机械通气或死亡、住院时长）；口服小分子 vs 单抗不同设计。
· RSV / 流感：症状缓解、住院、PCR 阳性持续时间。

注意点：耐药性监测（基因型/表型）、合并感染、特殊人群（孕妇、肾/肝损伤）。

· 免疫原性：抗体滴度（GMT）、细胞免疫（ICS / ELISpot）、中和抗体（PRNT / MNT）；
· 保护效力（VE）：临床终点，PCR/培养确诊的发病率差异；
· 免疫桥接：以免疫学指标预测临床保护（如 COVID-19 疫苗 mRNA 加强针、HPV）；
· 特殊场景：孕妇、婴幼儿、老年人群单独队列；
· 多价疫苗：每型单独评估免疫原性，整体 VE 通过桥接论证。

代谢 糖尿病 / 肥胖 / CKD

· HbA1c（糖化血红蛋白）：注册研究核心替代终点，反映 2–3 月平均血糖；
· 降糖效果：ΔHbA1c（基线 → 26/52 周）；
· 低血糖事件：率/百人年，level 1/2/3 分级；
· MACE / 心血管结局：CVOT（心血管结局研究），FDA 2008 后要求；
· 肾脏复合终点：eGFR 下降 ≥ 40% + ESRD + 肾脏死亡；
· 体重、腰围、血压、血脂：综合代谢改善。

新型降糖药（GLP-1RA、SGLT2i、DPP-4i）大多有 CVOT 试验，部分已显示心肾获益。

· 体重变化：% 体重下降 ≥ 5% / 10% / 15% 应答；
· 腰围、内脏脂肪面积（CT/MRI）：脂肪分布改善；
· 代谢综合指标：HbA1c、血压、血脂、肝脂肪（MRI-PDFF）；
· MASH（原 NASH）：肝活检 NASH CRN / SAF 评分、肝纤维化改善；
· 心肾事件：CVOT + 肾脏复合终点。

GLP-1RA（司美、度拉、利拉）、GIP/GLP-1（替尔泊肽）已展示显著减重（15%+），并拓展至心衰、阻塞性睡眠呼吸暂停、CKD 等适应症。

· eGFR：肾小球滤过率估计值；
· UACR：尿白蛋白/肌酐比；
· 复合肾脏终点：eGFR 持续下降 ≥ 40% + ESRD + 肾脏死亡；
· MACE+：CV 死亡 + 非致命 MI/卒中 + 因心衰住院；
· 特定病因：IgAN、APOL1、FSGS、ADPKD 等富集人群 + 病因特异终点（蛋白尿缓解、囊肿体积变化）。

SGLT2i（恩格列净、达格列净）、非甾体 MRA（finerenone）、内皮素受体拮抗剂（atrasentan）、补体抑制剂（iptacopan）等已拓展 CKD 适应症。

神经 AD / PD / MS / ALS

· CDR-SB（Clinical Dementia Rating-Sum of Boxes）：FDA 接受的金标准；
· ADAS-Cog / MMSE / MoCA：认知量表；
· PET 影像：淀粉（Aβ）、tau（MK-6240 等）；
· 脑脊液 / 血浆生物标志物：p-tau 181/217、Aβ42/40、GFAP、NfL；
· 功能终点：ADCS-ADL、ADCS-MCI-ADL；
· 家庭照护者负担：NPI、Zarit 量表。

2018–2024 抗淀粉（lecanemab / donanemab）已获批，验证淀粉级联假说与生物标志物作为替代终点。

· PD：MDS-UPDRS（运动 + 非运动 + 运动并发症）、关期时间（OFF time）、"wearing-off"、H&Y 分期；影像 DAT-SPECT、DTI、MRI。疾病修饰（DMT）研究通常 18–24 月以上，生物标志物（NfL、α-syn SAA）。
· MS：ARR（年化复发率）、EDSS 进展、MRI 病灶数、新发/扩大 T2、Gd+ 病灶；OCT 视网膜层厚度；
· ALS：ALSFRS-R（功能分级），FVC，生存期（生存概率比）；生物标志物 NfL；与基线 slope 比较的 slope analysis；
· 罕见神经病（FSHD、SMA、杜氏肌营养不良）常用自然史对照、Bayes、贝叶斯平台、安慰剂稀缺下的外部对照。

· MDD（重性抑郁）：MADRS、HAM-D；快速起效研究（氯胺酮、psilocybin）以早期 24h/72h 变化；难治性 TRD 定义需对齐（如至少 2 次足量足程治疗失败）。
· SCZ（精神分裂）：PANSS、CGI、PSP（功能）；阴性症状研究用 NSA-16；难治性（TRS）需 clozapine 失败史或不能耐受。
· 注意：高安慰剂效应、评分者间一致性、SUA（自杀/自伤事件）、AE 监控（EPS、QTc、MetS）、早期 drop-out。

罕见病 超罕见 <1/50000

· 患者数极少，多中心、跨国招募是常态；
· 疾病异质性高（基因型、严重程度、年龄分布）；
· 随机对照难以设计 → 大量使用自然史对照 / 外部对照 / 单一治疗臂；
· 适应性设计、Bayes、平台试验、再分析等方法学被广泛接受；
· 患者报告结局（PRO）与以患者为中心的终点（如行走 6MWT、上肢功能）成为关键；
· 长期自然史研究是申办者与监管者共同建立 disease model 的方法。

· AAV 基因治疗（如 SMA、AMD、Rett）：单次给药，长期持续表达；终点多为功能改善（运动里程碑、视力变化、生物标志物）；
· CAR-T（如 ALL、DLBCL、MM）：CR 率、MRD 阴性、PFS / OS；细胞因子风暴（CRS）、神经毒性（ICANS）管理；
· CRISPR/Cas9（如 SCD、β-地中海贫血）：编辑效率、HbF 表达、不良事件监测；
· 长期随访 15 年（FDA 2006 ATMP 指南），需建立 long-term registry。

· RWE（真实世界证据）：来自 EHR、医保数据库、患者登记、患者自报告等；
· 常见用途：外部对照、单臂试验辅助、上市后安全性、扩大适应症（label expansion）；
· 关键点：数据质量（数据源评估、缺失值、结局一致性）、倾向性评分（PS）、贝叶斯动态借用；
· FDA / EMA 2018 以来发布 RWE 框架，鼓励在罕见病中使用。

参考：FDA Real-World Evidence Program（2018）；EMA Data Analysis and Real World Interrogation Network（DARWIN-EU）。
